Tic-Tac-Toe Game

A simple Tic-Tac-Toe game built using HTML, CSS, and JavaScript.

Features

- Two-player gameplay
- Alternating X and O turns
- Winner detection
- New Game and Reset Game options

Technologies Used

- HTML
- CSS
- JavaScript

How to Run

1. Download or clone this repository.
2. Open "tic1.html" in your browser.
